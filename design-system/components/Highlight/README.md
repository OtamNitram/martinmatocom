# Highlight

Editorial pull quote: a short 48x2px rule in `highlight-rule` above one sentence set large in the `pull-quote` style (Source Serif 4, 32px, Medium Italic, 1.3 line height, balanced lines). No bar, no quote glyph, no fill, no shadow.

**Use** once per post, with the single sentence the whole post turns on. In an Article, right after the paragraph it comes from; the Article gives it `space-xl` (32px) above and below. Inside, it has `space-m` (16px) on top and `space-m` + `space-l` (40px) below, so the space under the quote mirrors the space above it (padding plus the 24px gap after the rule). It reads as a pause in the text, not as a new section: never add a divider or a heading around it. In a PostCard it sits between the excerpt and the Read More button.

**Consumer provides** the quote text as `children`: the sentence as written in the post, without quotation marks. Keep it under about 160 characters so it stays at two or three lines in the 680px column. Below 600px it switches to `pull-quote-mobile` (24px).

**Changed Nov 2026.** It used to be a mint quote glyph, 18px italic text and a 4px `accent` bar on the left. That version read as playful, almost childish, next to the serif body, so it moved to the editorial form above. The `quote` icon stays in the Icon set but the Highlight no longer uses it, and `accent` (mint) is now kept for the Card icon tile only.
