# Card

Pillar card with a mint icon tile, an H2 title and a short description, used for the About page's "Approach & Methodology" row.

**Use** in rows of three at 256px wide (desktop) or stacked on mobile.

**Consumer provides** `title`, the description as `children`, and an `icon` name (group, psychology, coach...).

Styling: `surfaces-white`, 1px `surfaces-elevation-20` border, `radius-card`, `shadow-elevation`, padding `space-l`. The tile is `accent` with the icon in `surfaces-highlights`, which is only 1.8:1 in the light theme; kept as designed.
