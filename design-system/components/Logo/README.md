# Logo

The Martín Mato mark: a block navy M with a teal script m over it, drawn small and centred inside a 57 × 48 frame (the frame's padding is what separates it from the name in the Header).

**Use** at 48px high in the Header, directly next to the name with no extra gap.

**Consumer provides** optional `height` (width follows the 57:48 ratio) and `label` (default "Martín Mato").

The script m is always `teal-500`. The M follows `text-primary`, so it turns light in the dark theme; the file draws it in `neutral-900` only (it would disappear on a dark page). The raw mark is also in the Logos asset group.
