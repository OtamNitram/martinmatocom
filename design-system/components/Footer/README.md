# Footer

Bottom band with the copyright line on the left and the links Posts, About, Contact and RSS right-aligned with 24px between them. Mobile stacks everything, centred, with a divider under the copyright and 24px between links.

**Use** once per page, full width, on `surfaces-highlights` with a 1px `surfaces-strokes` top rule.

**Consumer provides** `device`, optional `copyright` (default "© 2026 Martín Mato") and `links` (mark external ones `external`).
