# Link

Underlined text link used for header navigation and footer social links.

**Use** for navigation, never for primary actions (use Button). Default is underlined in `text-primary`; hover drops the underline; visited (Clicked in the file) turns `text-secondary`.

**Consumer provides** `children`, `href`; optional `external` (opens a new tab), `visited`, `current` (sets `aria-current`) and `icon`.
